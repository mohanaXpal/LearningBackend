## Student Portal

A simple Student Portal built with **Python and Flask** for practicing Flask fundamentals.

##  Features

- Student login with username and password
- Session-based authentication
- Student profile/dashboard
- Displays year, department, and subjects,cgpa
- Logout functionality
- Jinja2 template inheritance

##  Technologies Used

- Python
- Flask
- HTML
- CSS
- Jinja2

##  Project Structure

```text
StudentPortal/
├── app.py
├── requirements.txt
├── templates/
│   ├── base.html
│   ├── login.html
│   └── profile.html
└── static/
```
##  Note
This project does **not use a database**. Student information is temporarily stored in a Python dictionary . This is just  made for learning and practicing Flask fundamentals
